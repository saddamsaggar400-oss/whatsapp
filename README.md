# وصال — مراسلة خاصة للزوار ولوحة إدارة

تم تنفيذ النظام داخل المشروع الحالي، مع حفظ الواجهة السابقة والمجموعات للمدير على `/classic`، وعدم حذف الملفات القديمة أو رسائل SQLite الموجودة.

## الروابط

- `/` للزائر: محادثة واحدة خاصة دون حساب، وهوية ضيف آمنة تعود من المتصفح نفسه.
- `/admin` للمدير: تسجيل دخول آمن، وكل محادثات الزوار والردود والبحث والأرشفة والحذف من قائمته.
- `/classic` للمدير: الواجهة السابقة والمجموعات المحفوظة.

الخادم وقاعدة البيانات يتحققان من الصلاحيات على كل محادثة ورسالة ومرفق. لا يكفي تغيير الرابط أو إرسال طلب API يدوي للحصول على بيانات شخص آخر. الضيف لا يرى أسماء الزوار الآخرين ولا محادثاتهم.

## التشغيل المحلي من المشروع الحالي

Node.js 24 وpnpm 10.30.3 مطلوبان:

```bash
pnpm install --frozen-lockfile
npm --prefix artifacts/wisal-hosted ci
pnpm setup:account
pnpm dev
```

افتح `http://localhost:5173/` للزائر و`http://localhost:5173/admin` للمدير. يستخدم الدخول المحلي اسم `hhshklatifa` وكلمة المرور التي أعددتها بأمر الإعداد. لا تُشحن كلمة مرور ثابتة في المصدر. تُحدّث قاعدة SQLite تلقائيًا بترحيلات تحفظ البيانات الموجودة. يتطلب التشغيل المحلي أيضًا وجود المكونات والاعتماديات داخل `artifacts/wisal-hosted`، لأن الواجهتين تشتركان في التنفيذ نفسه.

```bash
pnpm build
pnpm start
```

البناء المحلي يقدّم الواجهة وAPI من خادم واحد على المنفذ 5000؛ يمكن تخصيصه بـ`PORT`. اضبط `CHAT_DB_PATH` و`CHAT_MEDIA_PATH` على قرص دائم، و`COOKIE_SECURE=1` مع HTTPS، و`TRUST_PROXY=1` فقط خلف وكيل موثوق واحد. لا تستخدم عدة خوادم مستقلة مع ملف SQLite واحد.

## النسخة المنشورة

توجد في [artifacts/wisal-hosted](artifacts/wisal-hosted/README.md)، وتستعمل Cloudflare D1 للرسائل والهويات، وR2 للصور والفيديو والصوت والملفات. قاعدة واحدة مشتركة للضيف والمدير. الدخول المنشور للمدير يستعمل حساب ChatGPT الموافق لبريد `ADMIN_EMAIL` السري، ويُربط بمعرّف هوية ثابت في قاعدة البيانات؛ كلمة المرور المحلية لا تُستخدم على الرابط المنشور.

تستقبل الواجهة الرسائل والكتابة والاتصال وعلامات القراءة عبر SSE. حالة الاتصال تعتمد على قناة فعلية بمهلة اكتشاف تصل إلى 20 ثانية عند الانقطاع المفاجئ. الحالات نصية أو صور أو فيديو، ينشرها المدير، وتختفي من الخادم والعرض بعد 24 ساعة. يوجد وضع ليلي ونهاري. تعديل صورة صاحب الحساب واسمه ونبذته ونشر الحالات محصور بالمدير. معلومات صاحب الحساب للزائر للقراءة فقط دون روابط للإدارة.

رقم الهاتف اختياري، يكتبه الضيف في إعدادات المحادثة ويظهر لصاحب الموقع فقط؛ لا يُكتشف من مجرد فتح الرابط ولا يُعتبر محققًا بـSMS. صوت الرسائل اختياري من الإعدادات، وبعد السماح بالصوت من المتصفح، ويعمل والصفحة مفتوحة.

حد المرفق 20 ميجابايت وحد التسجيل الصوتي دقيقتان. يتحقق الخادم من نوع الملفات ومحتواها، ويرفض الملفات التنفيذية وHTML وSVG والأنواع غير المتطابقة، ويطبق حدودًا للطلبات والرسائل والرفع. الرسائل محمية بصلاحيات وHTTPS، وليست مشفرة من طرف إلى طرف.

## التحقق

```bash
pnpm typecheck
pnpm test
npm --prefix artifacts/wisal-hosted exec -- tsc --noEmit
pnpm build
```
